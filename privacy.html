Política de privacidad de Pepito

Fecha de vigencia: 12 de noviembre de 2026

Responsable

Dra. Laura, anestesiologiaoccidente@gmail.com.

Datos a los que accede

Pepito accede, siempre de la cuenta de la propia usuaria y con su autorización explícita vía OAuth, a:

  • Correos de Gmail
  • Eventos de Google Calendar
  • Archivos de Google Drive
  • Hojas de Google Sheets
  • Documentos de Google Docs
  • Contactos (solo lectura)

Finalidad

Los datos se usan exclusivamente para gestionar la agenda, los turnos y la comunicación administrativa de la propia usuaria.

Uso y divulgación

Los datos no se venden, no se comparten con terceros, no se usan para publicidad y no se usan para entrenar modelos de IA de uso general.

El uso y la transferencia de la información recibida de las APIs de Google cumplen la Política de datos de usuario de los servicios de API de Google (Google API Services User Data Policy), incluidos los requisitos de Uso Limitado.

Almacenamiento

El token de acceso se guarda solo en el equipo personal de la usuaria. No hay servidores ni bases de datos externas de la app.

Revocación del acceso

La usuaria puede retirar el acceso cuando quiera en https://myaccount.google.com/permissions.

Contacto

Para cualquier consulta sobre esta política: anestesiologiaoccidente@gmail.com.
